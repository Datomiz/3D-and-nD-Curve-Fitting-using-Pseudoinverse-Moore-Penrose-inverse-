# 3D-and-nD-Curve-Fitting-using-Pseudoinverse-Moore-Penrose-inverse-
With the Pseudoinverse of a Matrix using the Moore–Penrose inverse method, it is possible to reverse the points of a dataset into a 3D or nD function that best fits the data. This code uses this ideia in many ways to achieve the best possible function to fit the data.


The code "Example of application.py" serves as a simple illustration of how one of the functions available in "Ajuste_curva_3D_r.py" can be used, employing simulated data to provide an example application. I used this code to estimate the error rate of a method I was applying to detect faults in telemetry data; however, the data is entirely simulated and does not represent actual data.
